# Kleanbotics — marketing site

Single-page, highly interactive marketing website for **Kleanbotics** by **InfinitiSense LLP** —
cloud-connected, EdgeAI-powered robots that clean solar panels on utility-scale farms and rooftops in India.

**Clean panels. Smarter power.**

## Stack

- **React 18 + Vite 5** — fast SPA, code-split heavy sections
- **Tailwind CSS 3** — custom navy + solar-amber design system
- **Framer Motion** — scroll reveals and interactive demos
- **Recharts** — fleet feed, market growth & revenue charts (lazy-loaded chunk)
- **Custom SVG** — layered robot and stylized India map (reliable fallback for 3D/Spline)

## Getting started

```bash
npm install
npm run dev       # dev server (http://localhost:5173)
npm run build     # production build -> dist/
npm run preview   # preview the production build
```
